# TaskOrbit

An offline, encrypted Android task app. Tasks are planned by day, week and month, and the app icon changes mood depending on how your day is going.

Status: early, solo student project. Built with Kotlin and Jetpack Compose. Data is stored in an encrypted on-device database. APK builds run on GitHub Actions.

Working on: an optional AI coach that looks at your month and suggests what to change.
